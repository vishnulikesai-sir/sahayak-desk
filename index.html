The problem this solves

At a university like RAJUVAS, the daily work is documents and data — leave applications, guest-house requests, exam-duty letters, animal research records. The people doing it are experts in veterinary science and administration, not in software or formal English drafting.

Before — पहले

  • Every official letter is drafted from scratch, or copied from an old file and edited by hand — slow, and full of leftover names and dates.
  • Research data sits in notebooks and loose sheets; averages and summaries are done on a calculator, animal by animal.
  • Most AI tools assume fluent English and a coding background — so staff simply don't use them.

With Sahayak Desk — अब

  • Pick a letter type, fill a simple form, get a clean, correctly formatted draft in Hindi or English — ready to copy or download.
  • Paste a list of animal weights or milk yields and get count, average, range and a chart in seconds, with the summary written out in both languages.
  • The interface speaks the user's language first: Hindi labels, plain words, no jargon.

How this was built with Codex

No feature here started in an editor. Each one started as a plain-language instruction — the same way a non-programmer would describe their problem — and Codex turned it into working code, which was then tested with real office examples and refined.

STEP 1

Describe the office problem, not the code

The first prompt named the user and the pain point — not a framework, not a library.

"Build a one-page tool for university office staff who write the same official letters again and again. A form on the left, a ready-to-use letter draft on the right. It must work in Hindi and English."
STEP 2

Add the second tool from a researcher's problem

Researchers were averaging animal weights by calculator. The prompt asked for the summary they actually report.

"Add a second tool: the user pastes readings like 'Animal 01, 342'. Show count, average, lowest, highest and a bar chart, plus one summary sentence in Hindi and English."
STEP 3

Test with real examples, fix what breaks

Each letter type was generated and read like a Dean's office would read it — dates, salutations, Hindi spellings — and every mismatch went back to Codex as a follow-up prompt.

"The Hindi leave letter should open with 'सेवा में' and close with 'भवदीय'. The date range must appear inside the body, not only in the subject line."
STEP 4

Make it work for the actual user

Big tap targets, Hindi labels next to English ones, works on a phone, works in the dark, and nothing the user types ever leaves the page.

"Make the whole page usable on a phone: stack the form fields, keep buttons large, and add a dark palette that follows the system setting."
