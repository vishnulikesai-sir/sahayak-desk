# Sahayak Desk (सहायक डेस्क)

A bilingual (Hindi/English) web tool built with Codex for non-technical staff at a veterinary university in Bikaner, Rajasthan — people who are Hindi-first and have no coding background.

## What it does

**Patra Sahayak (पत्र सहायक)** — drafts routine official letters in Hindi and English:
leave applications, guest house requests, exam duty letters and budget letters.
Copy the draft or download it as a text file.

**Data Sahayak** — summarises research and animal data pasted by the user:
count, average, range and standard deviation, with a bar chart and a plain-language
summary in both Hindi and English.

## Why I built it

Most faculty, researchers and admin staff at my university have real problems that
a small tool can solve — formatting letters, summarising data — but developer
content is almost always in English and aimed at programmers. Sahayak Desk is a
small example of what Codex makes possible for non-CS builders in Tier-2 India
when the guidance is in their own language.

## Run it

Open `index.html` in any browser. No server, no build step, no data leaves the browser.
